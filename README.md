# Currency Rate Bot

[![CI](https://github.com/d3c0r1x/currency-rate-bot/actions/workflows/ci.yml/badge.svg)](https://github.com/d3c0r1x/currency-rate-bot/actions/workflows/ci.yml)

Курсы валют в Telegram из официального XML ЦБ РФ. Без ключей, без сторонних библиотек для валют: только `xml.etree` из stdlib и HTTP.

Функционал: конвертация валют, история курсов, ежедневная рассылка сводки в 10:00 и пороговые алерты («уведомить, когда USD опустится ниже 90»).

## Команды

| Команда | Назначение |
|---|---|
| `/rates` | курсы основных валют (USD, EUR, CNY, ...) |
| `/rate USD` | курс одной валюты |
| `/convert 100 USD EUR` | конвертация |
| `/history USD` | история курса за последние дни |
| `/watch USD` | добавление валюты в личный watchlist |
| `/watchlist` | список валют |
| `/alert USD 90 below` | алерт «уведомить, когда USD < 90» |
| `/alerts` | список алертов |
| `/daily` | подписка/отписка от ежедневной рассылки |

## Особенности парсинга ЦБ

1. **Кодировка windows-1251.** Официальный XML ЦБ (`cbr.ru/scripts/XML_daily.asp`) отдаётся в windows-1251; чтение как UTF-8 приводит к некорректному отображению названий валют. Решение: загрузка байтов с последующей обработкой expat'ом, который определяет кодировку по декларации.
2. **Десятичная запятая.** Курсы приходят в формате `89,9876`. Прямое преобразование `float()` невозможно; требуется замена запятой на точку.
3. **`Nominal`.** Для валют с большим номиналом значение не равно 1: у JPY — 100, у KZT — 1000, у BYN — 100. Курс необходимо делить на номинал, иначе конвертация будет некорректной: например, для JPY курс указан за 100 иен, а не за одну.

## Принцип работы

- `cbr_api.py` парсит XML, `pydantic` валидирует модель курса;
- SQLite хранит историю и подписки;
- **APScheduler** в 10:00 выполняет рассылку подписчикам и раз в 60 минут проверяет пороговые алерты;
- алерты **одноразовые**: после срабатывания снимаются, что исключает повторные уведомления каждый час;
- демо-режим (`CURRENCY_DEMO_MODE=1`) подставляет встроенные курсы для запуска без сети.

## Запуск

```bash
python -m venv .venv
pip install -r requirements.txt
export CURRENCY_BOT_TOKEN=123456:ABC...   # токен от @BotFather
export CURRENCY_DEMO_MODE=1               # 0 — официальный ЦБ РФ
python bot.py
```

На Windows — `start.bat` (токен из корневого `.env`).

## Структура проекта

```
bot.py          — команды, конвертация, рассылка, алерты
cbr_api.py      — парсинг XML ЦБ (байты/кодировка/номинал), демо-курсы
alerts.py       — логика пороговых алертов (одноразовые, сравнение)
db.py           — aiosqlite: история, подписки, watchlist, алерты
middlewares.py  — троттлинг и логирование
config.py       — настройки из переменных окружения
tests/          — 9 тестов (парсинг XML, кодировка, номинал, конвертация, алерты, история, подписки)
```

## Планы развития

- курсы по расписанию два раза в день (не только рассылка в 10:00);
- кросс-курсы между любыми двумя валютами без посредника USD;
- мини-график за месяц в чате.
