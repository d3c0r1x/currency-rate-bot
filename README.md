# Currency Rate Bot

Курсы валют в Telegram из первого источника — официального XML ЦБ РФ. Без ключей, без сторонних библиотек для валют: только `xml.etree` из stdlib и HTTP.

Умеет конвертировать валюты, помнить историю, рассылать сводку каждый день в 10:00 и — моё любимое — **сторожить пороговые алерты**: «напиши мне, когда USD упадёт ниже 90».

## Команды

| Команда | Что делает |
|---|---|
| `/rates` | курсы основных валют (USD, EUR, CNY, ...) |
| `/rate USD` | курс одной валюты |
| `/convert 100 USD EUR` | конвертация |
| `/history USD` | история курса за последние дни |
| `/watch USD` | добавить валюту в личный watchlist |
| `/watchlist` | мои валюты |
| `/alert USD 90 below` | алерт «уведоми, когда USD < 90» |
| `/alerts` | мои алерты |
| `/daily` | подписаться/отписаться от ежедневной рассылки |

## Парсинг ЦБ: три подводных камня

1. **Кодировка windows-1251.** Официальный XML ЦБ (`cbr.ru/scripts/XML_daily.asp`) отдаётся в windows-1251, и если прочитать его как UTF-8 — мусор вместо «Доллар США». Решение: качаем байты и даём их expat'у, он сам разберётся по декларации.
2. **Десятичная запятая.** Курсы приходят как `89,9876` — с запятой. Строку нельзя просто `float()`, нужно менять запятую на точку.
3. **`Nominal`.** У «дорогих» валют номинал не 1: у JPY это 100, у KZT — 1000, у BYN — 100. Курс надо делить на номинал, иначе конвертация враньё. Первое время у меня JPY стоил «миллион рублей за иену» — теперь нет.

## Как это работает

- `cbr_api.py` парсит XML, `pydantic` валидирует модель курса;
- SQLite хранит историю и подписки;
- **APScheduler** в 10:00 делает рассылку подписчикам и раз в 60 минут проверяет пороговые алерты;
- алерты **одноразовые**: сработал — снимается. Иначе бот спамил бы «USD всё ещё ниже 90» каждый час.
- демо-режим (`CURRENCY_DEMO_MODE=1`) подставляет встроенные курсы — для запуска без сети.

## Запуск

```bash
python -m venv .venv
pip install -r requirements.txt
export CURRENCY_BOT_TOKEN=123456:ABC...   # токен от @BotFather
export CURRENCY_DEMO_MODE=1               # 0 — официальный ЦБ РФ
python bot.py
```

На Windows — `run_bot6.cmd` (токен из корневого `.env`).

## Из чего состоит

```
bot.py          — команды, конвертация, рассылка, алерты
cbr_api.py      — парсинг XML ЦБ (байты/кодировка/номинал), демо-курсы
alerts.py       — логика пороговых алертов (одноразовые, сравнение)
db.py           — aiosqlite: история, подписки, watchlist, алерты
middlewares.py  — троттлинг и логирование
config.py       — настройки из переменных окружения
tests/          — 7 тестов (парсинг XML, кодировка, номинал, алерты, история)
```
